Installation & Project Anatomy

The runtime has no third-party dependencies. Install Thread with Wally for the simplest setup, or copy the package manually if you are not using Wally.

Project Anatomy

Thread/
├── src/                  -- copy/map this to ReplicatedStorage/Packages
│   ├── init.luau        -- Wally/Rojo package root + lifecycle
│   ├── Channel.luau     -- everything networking-related (RemoteEvents/Functions)
│   ├── Promise.luau     -- async primitive used by Thread.Start()/OnStart()
│   ├── Generated/       -- generated package metadata
│   └── Util/
│       ├── Signal.luau      -- fast in-process pub/sub (no Instance overhead)
│       ├── Trove.luau       -- cleanup/janitor helper
│       ├── TableUtil.luau   -- table helper functions
│       ├── Option.luau      -- explicit nil-handling wrapper
│       ├── EnumList.luau    -- custom, comparable enums
│       ├── MathUtil.luau    -- lerp, range remapping, fuzzy equality
│       └── TimerUtil.luau   -- debounce/throttle function wrappers
├── Tests/
│   ├── TestRunner.luau   -- ~30-line assert-based test runner, no TestEZ
│   └── Thread.spec.luau  -- the actual test suite
├── generated/            -- service manifest and static client types
├── default.project.json  -- published package model
├── dev.project.json      -- local development/test place
├── integration.project.json
├── thread.config.json    -- version and generation source
├── rokit.toml
├── wally.toml
├── README.md
├── CHANGELOG.md
└── LICENSE

Installation

Wally (recommended)

Add Thread to your game's wally.toml:

[dependencies]
Thread = "realthonik/thread@2.0.0"

Run wally install, then map Wally's Packages directory into ReplicatedStorage.Packages with Rojo.

"ReplicatedStorage": {
  "Packages": {
    "$path": "Packages"
  }
}

Thread is then available as:

local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Thread = require(ReplicatedStorage.Packages.Thread)
That's it
Thread has no runtime dependencies of its own. Wally installs the package and Rojo mounts it as a single Thread ModuleScript.

Manual installation

If you are not using Wally, preserve the package hierarchy under a ModuleScript named Thread:

ReplicatedStorage
└── Packages
    └── Thread
        ├── Channel
        ├── Promise
        ├── Generated
        └── Util
            ├── Signal
            ├── Trove
            ├── TableUtil
            ├── Option
            ├── EnumList
            ├── MathUtil
            └── TimerUtil

Where your own code goes

There is no fixed location for your own game code — Thread.Register(folder) just points at whatever folder you keep your services/controllers in. The conventional layout is: 

ServerScriptService
└── Services
    ├── MoneyService.luau
    └── DataService.luau

StarterPlayer
└── StarterPlayerScripts
    └── Controllers
        └── HudController.luau
