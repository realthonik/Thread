01

The idea

One service table, one public contract.

Define server behavior and the client surface in the same place. Thread builds the connection, including rate limits and invoke timeouts, instead of leaving a tangle of remote instances behind.

Client

The server's Client table is the API the client receives. No string-matching two ends by hand.

02

Quick start

Register, then start.

ServerScriptService/Server.server.lua
local Thread = require(game:GetService("ReplicatedStorage").Packages.Thread)

Thread.Register(game:GetService("ServerScriptService").Services)
Thread.Start():catch(warn)
Services/MoneyService.luau
local Thread = require(game:GetService("ReplicatedStorage").Packages.Thread)

local MoneyService = Thread.CreateService({
    Name = "MoneyService",
    Client = {
        GetMoney = function(self, player)
            return self.Server:GetMoney(player)
        end,
        MoneyChanged = Thread.CreateSignal(),
        Jackpot = Thread.CreateProperty(0),
    },
})

local balances = {}

function MoneyService:GetMoney(player)
    return balances[player] or 0
end

return MoneyService

On the client, Channel.BuildClient("MoneyService") returns a proxy with :GetMoney(), a connectable MoneyChanged signal, and an observable Jackpot property.
